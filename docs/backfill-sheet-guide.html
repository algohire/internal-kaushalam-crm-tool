How to Fill the Backfill Sheet

For callers and leads who validate employer requirements over the phone and need to enter data into the CRM in bulk.

Quick start
  1. You'll receive a CSV file named like backfill-export-2026-09-03.csv
  2. Open it in Excel or Google Sheets
  3. Fill in the green columns (M onwards) — leave the grey columns (A–L) untouched
  4. Save as CSV (UTF-8) and return to the admin

Understanding the Sheet

The sheet has one row per role per company. If a company needs a "Packing Helper" and a "Machine Operator", that company appears in two rows.

Columns You Should NOT Edit (A–L)

These come from the EDB database. They give you context about the company and role.

Columns You Fill In (M onwards)

Fill these based on what the employer told you on the call. Leave blank if unknown — only fill what you've confirmed.

required_count_validated

Column M Required for handoff

What: The actual number of openings the employer confirmed.

Ask: "How many [role] positions do you currently need to fill?"

Enter a whole number: 60, 15, 120
This may differ from the EDB count — enter what the employer says.
If they say "same as before", copy the required_count value from column I.

qualification

Column N Required for handoff

What: Minimum educational qualification needed for this role.

Ask: "What is the minimum qualification you need for [role]?"

Enter the qualification UUID from the master list provided separately. Multiple qualifications separated by semicolons.

Single: 51104747-dfa9-42c3-...
Multiple: 51104747-...;e24acb59-...
⚠ Your admin will share the qualification ID list. Use the UUIDs, not the names.

experience_from & experience_to

Columns O–P Required for handoff

What: Minimum and maximum years of experience. Range 0–15.

Ask: "How many years of experience do you need?"

Fresher only → from: 0, to: 0
1 to 3 years → from: 1, to: 3
5+ years, any senior → from: 5, to: 15
⚠ "To" must be ≥ "From". Both must be 0–15.

gender_preference

Column Q Optional

Enter: Any, Male, or Female. Leave blank if no preference.

age_limit

Column R Optional

Free text. Examples: 18–35, 21–40, Below 30

salary

Column S Optional

What: Monthly salary in ₹. Number only, no ₹ symbol or commas.

₹12,500/month → 12500
₹8,000/month → 8000
If a range, enter the lower end.

pwd

Column T Optional

What: Is this role open to Persons with Disabilities (diversity hiring)?

Enter yes if employer specifically mentioned PWD/diversity hiring. Otherwise leave blank.

classification

Column U Required for handoff

What: Where should this requirement be routed? Enter exactly one value:

ValueWhen to use
kaushalamEmployer wants job-ready candidates. Normal hiring — goes to Scheduling team for a placement drive. Most common.
collectorUnskilled or semi-skilled labour, needs local mobilisation through the district Collector's office. Typically daily-wage or seasonal work.
apssdcCandidates need training first. Goes to APSSDC via EDB for skill development before placement.

Decision guide: Can our assessed candidates fill this?
Yes → kaushalam · Need local villagers, no skill → collector · Need training first → apssdc

collector_district

Column V Required if collector

What: Which district should the Collector ticket go to? Spelling must match exactly.

Alluri Sitharama Raju · Anakapalli · Anantapuramu · Annamayya · Bapatla · Chittoor · Dr. B.R. Ambedkar Konaseema · East Godavari · Eluru · Guntur · Kakinada · Krishna · Kurnool · Nandyal · NTR · Palnadu · Parvathipuram Manyam · Prakasam · Sri Potti Sriramulu Nellore · Sri Sathya Sai · Srikakulam · Tirupati · Visakhapatnam · Vizianagaram · West Godavari · YSR Kadapa

handoff_comment

Column W Required for handoff

What: Context for the team receiving this requirement. 1–2 sentences covering:

• Special conditions (shift timings, transport, accommodation)
• Start date if mentioned
• Employer preferences

"Day shift only, ₹12,500 + ESI/PF. Women preferred for line 3. Walk-in at Guntur unit."
"Festive-season hiring, 60 heads, no qualification. Within 15 km of Gannavaram. Start 15 Sep."

new_status

Column X Optional

What: Update the requirement status. Leave blank to keep as-is.

handed_over_collector

Handing to APSSDC for training
no_requirement
Employer no longer hiring for this role
future
Employer will hire later, not now
not_operational
Company is closed or not running
do_not_call
Employer asked not to be contacted

Rules to Remember

  1. Never edit columns A–L — they are reference data from EDB
  2. Never delete the requirement_id column — the system uses it to match rows on import
  3. For handoffs (any handed_over_* status), all of these must be filled: validated count, qualification, experience from/to, classification, and handoff comment. If collector: also the district.
  4. Leave blank = no change — if you don't know a value, leave the cell empty. The system only updates what you fill.
  5. One row = one role — if a company has two roles, fill both rows independently
  6. Save as CSV (UTF-8) when done — not .xlsx

After You're Done

  1. Save the file as CSV
  2. Send it to the admin
  3. Admin runs the import, which will:
    • Update all the requirement records you filled
    • Mark tasks as completed for companies you validated
    • Queue handoffs for the downstream teams
  4. Admin shares a report of what was updated and any errors
